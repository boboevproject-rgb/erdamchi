# Erdamchi — пост для Threads

Видео: `marketing/erdamchi-threads.mp4` (1080×1350, 4:5, ~20 с, без звука — в ленте Threads автоплей всё равно немой).

## Основной пост (≈430 знаков, лимит 500)

Сделал Erdamchi — бесплатный конвертер файлов для Windows, который работает одним жестом.

Зажимаешь Ctrl, тянешь файл — под курсором раскрывается круглое меню форматов. Бросаешь на нужный — готовый файл появляется рядом с оригиналом.

255 форматов: HEIC → JPG, PDF ↔ Word, видео, аудио, книги, архивы, CAD. Всё офлайн, ничего не уходит в облако, Office не нужен.

Открытый код (MIT): github.com/boboevproject-rgb/erdamchi

## Ответ 1 в треде (как пользоваться)

Приложение живёт в трее и не мешает. Файл → Ctrl + перетаскивание → меню. Колёсико мыши переворачивает его на обратную сторону — там инструменты: сжать, обрезать, убрать фон, повернуть, собрать ZIP. Можно бросить сразу десяток файлов — сконвертирует пачкой.

## Ответ 2 в треде (честно про происхождение)

Erdamchi — мой форк открытого проекта Filee (лицензия MIT): переименовал, перевёл на свои данные, собрал под Windows и буду развивать дальше под свои задачи. Готовый установщик скоро выложу в релизы, пока собрать можно из исходников — инструкция в README.

## Короткая английская версия (если нужна)

Meet Erdamchi — a free, offline file converter for Windows that works with one gesture.

Hold Ctrl, drag a file — a round menu of formats opens under the cursor. Drop it on the one you need and the result lands next to the original.

255 formats: HEIC → JPG, PDF ↔ Word, video, audio, e-books, archives, CAD. No cloud, no Office needed.

Open source (MIT): github.com/boboevproject-rgb/erdamchi
